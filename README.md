# Hipotecas - Banco Ciudad (prototipo Daniel Córdoba)

Sistema prototipo para gestión de préstamos hipotecarios.

## Funcionalidades

### Perfil Escribano/a
- Turnos para escrituración
- Turnos para cancelación
- Adjuntar factura de honorarios
- Entregadas al cliente
- Cambio de clave

### Perfil Administrador
- Consulta y asignación de legajos
- Visualización de turnos
- Recepción y carga de letras
- Archivo físico y electrónico
- Entregas para cancelaciones
- Registro de escribanos
